# Вовремя

Telegram-бот и Mini App для личных напоминаний о приёме лекарств и уколах.

## Что уже есть

- гибкие расписания, повторные напоминания и история приёмов;
- Mini App с экранами «Сегодня», «Курсы», «Семья» и «История»;
- семейный доступ: владелец может назначать и отслеживать приёмы близкого;
- экспорт и удаление пользовательских данных;
- PostgreSQL, Redis, Docker Compose и миграции Alembic.

> «Вовремя» не назначает лечение и не проверяет совместимость препаратов.

## Быстрый старт

```bash
cp .env.example .env
# укажите MEDICATION_TELEGRAM_BOT_TOKEN в .env
docker compose up --build
```

Проверка сервиса: `http://localhost:8000/health`.

Для просмотра Mini App с безопасными демонстрационными данными без Telegram-бота:

```bash
docker compose -f compose.demo.yaml up --build
```

Откройте `http://127.0.0.1:8002/mini-app`.
